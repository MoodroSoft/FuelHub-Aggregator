## Настройка окружения

В данном проекте используется пакетный менеджер `uv`.

#### Создание виртуального окружения
```
uv venv .venv
```

#### Установка зависимостей

```
uv sync
```

#### Добавление нового пакета
```
uv add <package_name>
```

#### Удаление пакета
```
uv remove <package_name>
```

## Команды

> Для работы с проектом необходимо установить утилиту `make`

### Запуск

#### Сборка Docker-образа
```sh
make dc-build
```

#### Запуск контейнеров
```sh
make dc-up
```

#### Остановка и удаление контенеров
```sh
make dc-down
```

#### Перезапуск контейнеров
```sh
make dc-restart
```

### Миграции alembic

#### Создание новой миграции
```sh
make al-new message="Новая миграция"
```

#### Применение миграций
```sh
make al-up
```

#### Откат на предыдущую миграцию
```sh
make al-down
```

### Тесты

#### Запуск тестов
```sh
make pytest
```

#### Запуск тестов в многопоточном режиме
```sh
make pytest-xdist
```
По умолчанию запускаются 8 потоков. Этот параметр можно изменить с помощью переменной `workers`:
```sh
make pytest-xdist workers=4
```

Если необходимо запустить `pytest` (`pytest-xdist`) для определенной папки/файла/кейса, то нужно задать переменную `test`. Путь до тестов указывается относительно папки `tests/`:
```sh
make pytest test="api"  # тесты в папке api
make pytest test="api/test_auth.py"  # тесты в файле api/test_auth.py
make pytest test="api/test_auth.py::test_login_success_200"  # тест из файла api/test_auth.py
```
