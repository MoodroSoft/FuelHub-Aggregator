### Этап 1: Создание фундамента — База данных и модели
**Цель:** Спроектировать "хранилище" для наших данных.

- [ ] **1.1 Описать данные с помощью моделей SQLAlchemy:**
  - **Модель** — это Python-класс, который описывает структуру таблицы в базе данных. Это наш способ говорить с базой на языке Python.
  - ✅ `FuelType` — **ГОТОВЫЙ ПРИМЕР.** Изучите файл `src/models.py`, чтобы понять, как она сделана.
  - ✏️ `GasStation` — ваша задача создать эту модель по аналогии.
  - ✏️ `ServiceType` — и эту модель тоже.
- [ ] **1.2 Настроить подключение к PostgreSQL:** Указать в настройках, как нашему приложению найти базу данных (скорее всего, уже настроено).
- [ ] **1.3 Создать "миграции" с помощью Alembic:**
  - **Миграция** — это скрипт, который обновляет структуру базы данных. После создания моделей `GasStation` и `ServiceType` вам нужно будет создать новую миграцию, чтобы добавить их таблицы в БД.
- [ ] **1.4 Наполнить базу тестовыми данными (сиды):** Создать скрипты, которые заполнят таблицы `gas_stations` и `service_types` первоначальными данными.

**Результат:** У нас есть работающая база данных со всеми необходимыми таблицами и тестовыми данными.
